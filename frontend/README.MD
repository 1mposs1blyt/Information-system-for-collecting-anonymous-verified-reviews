# Система сбора анонимных верифицированных отзывов

Репозиторий содержит информационную систему для безопасного, анонимного и подтвержденного сбора отзывов.

## 🏢 Архитектура и структура проекта

Проект разделен на логические слои:

* `src/components/screens` — Основные экраны приложения (AdminScreen, UserScreen).
* `src/components/medium` — Среднеуровневые компоненты бизнес-логики:
  * `/admin` — Авторизация и панели статистики администратора.
  * `/user` — Компоненты для работы с кодами верификации пользователей.
* `src/App.tsx` — Корневой компонент маршрутизации.

## 🚀 Пошаговое руководство по локальному запуску

### Вариант 1. Обычный локальный запуск (Node.js/npm)

1. Установите зависимости проекта:
   ```bash
   npm install --legacy-peer-deps
   ```
2. Скопируйте демонстрационные настройки окружения:
   ```bash
   cp .env.example .env
   ```
3. Запустите сервер разработки Vite:
   ```bash
   npm run dev
   ```

### Вариант 2. Контейнеризированный запуск (Docker Compose)

1. Убедитесь, что Docker и Docker Compose установлены.
2. Соберите и запустите контейнеры в фоновом режиме:
   ```bash
   docker-compose up -d --build
   ```
3. Приложение будет доступно по адресу: `http://localhost:5173`
